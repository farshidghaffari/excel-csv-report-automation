# Sample Output

Running the demo creates:

```text
output/sales_report.xlsx
```

The Excel file includes:

## Cleaned Data

Normalized and validated rows with calculated `total_revenue`.

## Monthly Summary

Revenue and order counts grouped by month.

## Category Summary

Revenue grouped by product category.

## Product Summary

Revenue grouped by product.

## Report Info

Basic metadata such as source file, total rows, total revenue, and date range.
